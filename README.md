# 易闻查词 · 小红书违禁词工作台

垂直小红书的违禁词检测工具。核心差异点：**每个标红都给出「为什么标红 → 出处依据 → 你的赛道能不能用 → 真实案例 → 改写建议」**，跑通「检测 → 原因 → 改写 → 发布预览/建议 → 历史复盘」闭环。

## 功能

- **检测工作台**：通用 Auto 词库 + 美妆/医疗/母婴等垂类赛道；四级风险标红（🔴禁用 / 🟠高危 / 🟡提醒 / 🔵需资质可用）
- **出处详情面板**：引用《广告法》第九条、《化妆品监督管理条例》、小红书社区公约等原文条款
- **AI 一键改写**：原文 ↔ 改写左右对比，合规评分变化可视
- **发布预览**：真实小红书笔记样式 + 合规评分 + 发布建议
- **历史复盘 / 我的词库 / 会员定价 / 词库后台**

## 运行

基于 **Vite** 构建，本地不再依赖任何 CDN（React 等随产物打包）。

```bash
npm install        # 首次安装依赖
npm run dev        # 开发模式，热更新
npm run build      # 生产构建，产物在 dist/
npm run preview    # 预览构建产物
npm run test:engine  # 跑检测内核的抗对抗评测
```

开发模式默认 `http://localhost:5173`。构建产物 `dist/` 为纯静态文件，可直接传到对象存储 / CDN（`base` 已设为相对路径，支持任意子路径部署）。

  ui.jsx          # 共享 UI 基元、评分环、笔记预览
  workspace.jsx   # 高亮渲染、问题清单、出处详情卡

## 说明

- 词库现为 88 条主词、含别名共 400+ 个匹配形，覆盖极限词/医疗功效/特殊宣称/站外导流/虚假诱导/数据造假六类。精简词条（仅词/别名/等级/分类）会自动继承分类默认的出处/理由/改写，便于规模化扩充到数千条；生产需继续扩充并接入平台规则更新。
- 检测引擎已是抗对抗匹配：归一化（全角→半角/小写）+ 压缩（穿透夹字/夹符号/emoji/零宽/空格等绕审写法）+ Aho-Corasick 多模匹配。后续可叠加拼音/谐音与语义模型进一步提召回。
- 会员状态、历史记录、自定义词库存于浏览器 localStorage（后续接账号体系后迁服务端）。

> 检测结果仅供参考，不具有法律效力。部分标注的违禁词在持有相应资质或特定类目下可以使用，请结合自身情况判断。
